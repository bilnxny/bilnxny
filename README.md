## 🔴 About

**Muhammed Bilal TA** — Penetration Tester, Red Team Operator, and Bug Hunter based in **Kerala, India**.

I break systems to make them safer. 3+ years hunting vulnerabilities in web applications, networks, and Active Directory environments. I also mentor beginners — from zero to their first bug bounty payout.

**What I do:**
- 🎯 **Bug Bounty** — Web apps, APIs, business logic flaws
- ⚔️ **Red Teaming** — AD attacks, lateral movement, C2 operations
- 🔍 **OSINT & Recon** — Footprinting, asset discovery, intelligence gathering
- 🧠 **Mentoring** — Guiding newcomers into cybersecurity

**Domains:** Web Exploitation · Network Pentesting · Active Directory · OSINT · Aerospace Security Research
